# Sprint 2.2 — Visual restoration

The pattern matrix still uses two internal groups because these groups define
the diagonal structures. They are implementation details and are not presented
to the user as Pink and Green.

The renderer now uses neutral CSS classes:

- `pattern-a`
- `pattern-b`

Their visual appearance follows FretMaster Studio 3.2:

- dark wooden fingerboard
- metallic fret dividers
- graduated string thickness
- translucent red and green structural regions
- yellow circular target marker
