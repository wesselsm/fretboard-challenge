# Guitar Neck Pilot 1.0.0 Stable - Release Notes

Guitar Neck Pilot 1.0.0 Stable is the first complete adult release of the Pattern & Interval Trainer.

The stable release preserves the original abstract six-by-sixteen training matrix while providing scale management, custom pattern editing, randomized cyclic offsets, fair performance scoring, persistent statistics, mobile support and mirrored left/right-handed presentation.

## Brand identity

The target circle `◎` is the central product symbol. It represents the marked training position, visual focus and the gradual development of fretboard control.

**Product:** Guitar Neck Pilot  
**Descriptor:** Pattern & Interval Trainer  
**Tagline:** Train patterns. Master the fretboard.

## Data

The application uses browser LocalStorage. Existing data created by the RC build remains available because the internal storage namespace is intentionally retained for upgrade compatibility.

## Validation status

JavaScript syntax, required assets, internal links, branding strings and package integrity are checked automatically during the release build. Cross-browser interaction and device behavior remain manual checks and are documented in `REGRESSION_CHECKLIST.md`.
