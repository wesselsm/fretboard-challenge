# Changelog

## 1.0.1 Stable - 2026-07-30

- Fixed mobile stacking of the sticky interval-answer bar.
- The fretboard and strings can no longer render over the answer buttons while scrolling.
- Added safe-area padding for phones with a gesture/navigation inset.

### Added
- Final Guitar Neck Pilot identity and target-circle brand symbol
- Stable splash screen, logo suite, favicon and application icons
- Pattern & Interval Trainer subtitle and final tagline
- User manual, brand guide and stable release documentation

### Included from the release-candidate cycle
- Scale library and Pattern Designer
- JSON import and export
- Persistent training statistics and trend analysis
- Accuracy-and-time performance scoring version 2
- Random cyclic pattern offsets
- Left- and right-handed fretboard presentation
- Responsive mobile layout and streamlined answer feedback

### Fixed
- Target marker persistence after round start
- Scale switching during active training
- Mobile fretboard overflow and answer-button wrapping
- Unfair score ordering for equally accurate rounds
